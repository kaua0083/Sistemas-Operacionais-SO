# Contribuindo para o Ronnin System

Agradecemos o seu interesse em contribuir para o Ronnin System! São contribuições como a sua que fazem este projeto evoluir.

## Como Posso Contribuir?

### 1. Relatando Bugs
Antes de criar um relato de bug, verifique as *Issues* existentes para evitar duplicatas. Ao criar um relato de bug, inclua o máximo de detalhes possível:
* **Use um título claro e descritivo.**
* **Descreva os passos exatos para reproduzir o problema.**
* **Forneça exemplos específicos para demonstrar o erro.**
* **Descreva o comportamento observado e o comportamento esperado.**

### 2. Sugerindo Melhorias
Sugestões de novas funcionalidades são sempre bem-vindas! Ao sugerir uma melhoria, por favor:
* **Use um título claro e descritivo.**
* **Forneça uma explicação detalhada da funcionalidade sugerida.**
* **Explique por que essa melhoria seria útil para o projeto.**

### 3. Pull Requests (Envio de Código)

Siga estes passos para enviar suas alterações:

1. **Faça um Fork do Repositório:**
   Clique no botão "Fork" no canto superior direito da página do repositório.

2. **Clone o seu Fork:**
   ```bash
   git clone https://github.com/SEU-USUARIO/ronnin-system.git
   cd ronnin-system
   ```

3. **Crie uma Branch para a sua Feature:**
   ```bash
   git checkout -b feature/nome-da-sua-feature
   ```

4. **Commite suas Alterações:**
   Escreva mensagens de commit claras e objetivas:
   ```bash
   git commit -m "feat: adiciona suporte para nova funcionalidade"
   ```

5. **Envie as alterações para o seu Fork:**
   ```bash
   git push origin feature/nome-da-sua-feature
   ```

6. **Abra um Pull Request:**
   Vá até o repositório original no GitHub e clique em "Compare & pull request". Descreva suas alterações e vincule as *Issues* relacionadas, se houver.

## Guia de Estilo

* Mantenha o padrão de código existente no projeto.
* Escreva códigos limpos, legíveis e com comentários onde necessário.
* Garanta que os testes existentes continuem passando antes de enviar o PR.

Muito obrigado por sua contribuição! 🚀
